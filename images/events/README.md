# Event photo slots

Drop photos into this folder using these filenames. The story pages show designed placeholders until each image is added.

- WLV fellowship: `wlv-01.JPG` (already added) and `wlv-02.jpg` through `wlv-21.jpg`
- AAA scholarship: `aaa-01.jpg` through `aaa-05.jpg`
- DevFest Carnival: `devfest-01.jpg` through `devfest-06.jpg`

Portrait-oriented photos fit the portrait tiles. Landscape group photos fit the wide tiles. Captions stay over the photos after they are added. JPG, PNG, and WebP content work; to use a different extension, update the matching `src` in the relevant HTML page.
